# siaSearch
Part of Internet search technology assignement

## How to Run

1. **Clone the Repository**  
    ```bash
    git clone https://github.com/eduardsosh/siaSearch.git
    cd siaSearch
    ```

2. **Install Dependencies**  
    Ensure you have Python installed. Then, install the required packages:
    *USE VENV!*
    
    ```bash
    pip install -r requirements.txt
    ```

3. **Run the Application**  
    run main.py to download data csv's and load them into a database
    ```bash
    python main.py
    ```

4. **Data analysis**  
    Run scripts of interest to see some results:
    - get_income_by_year.py
    - get_10_profitable.py
    - search_reports.py

    ```bash
    python <script>
    ```
